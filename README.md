# MARS Team Creepers Design

This is the official repository for the MARS Rocket design for Team Creeper. 

## AV Bay Design
This is the Avionics Bay, designed in Blender and tested via various CAD software. 

<img width="268" height="501" alt="image" src="https://github.com/user-attachments/assets/f740835b-d246-4f51-8c4c-3a88daf35deb" />

The actual avionics consist of a custom PCB to collect flight data, and a 3.7V LiPo 503450 battery.  

## Rocket Design
The rocket was tested via OpenRocket and modelled in Blender, later converted to a STEP file for CAD inspection via OnShape.

The OnShape link can be found via the link [here](https://cad.onshape.com/documents/f616996cf811972a629b35e6/w/17eb850e09ddeacffa6e7bb9/e/c1c2f7f3cfb6706efa76b407?renderMode=0&uiState=6af653603eb01bee9c4963b9).
